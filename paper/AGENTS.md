# Règles générales

Ce dépôt contient un article de recherche sur le partage opportuniste
d’infrastructures RAN entre opérateurs.

Les réponses doivent être concises.

Avant toute réponse :
- lire PROJECT_CONTEXT.md ;
- lire les fichiers LaTeX concernés ;
- préserver les notations existantes ;
- ne jamais renommer une variable sans autorisation ;
- ne jamais modifier une preuve ou une hypothèse silencieusement ;
- distinguer résultat démontré, intuition, conjecture et observation numérique ;
- rédiger dans un français académique, précis et concis ;
- montrer le diff avant toute modification importante ;
- ne modifier que les fichiers nécessaires ;
- compiler main.tex après une modification et signaler les erreurs.

Pour les demandes d’analyse :
- ne pas modifier les fichiers sauf demande explicite ;
- citer le fichier et les lignes concernées ;
- vérifier la cohérence avec les parties 3, 4 et 5.

Pour les demandes d’édition :
- conserver les labels, références, commandes et structure LaTeX ;
- éviter les reformulations purement stylistiques sans gain scientifique ;
- ne pas introduire de nouvelle notation inutile.
